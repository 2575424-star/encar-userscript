# VECTOR Encar Calculator

Калькулятор на страницах Encar; подготовка интеграции с VECTOR CRM.

## Исправления

- Нулевые расходы и ручные платежи сохраняются; неизвестные суммы не превращаются в ноль итоговой стоимости.
- Округление общей суммы после расчёта, без преждевременного округления цены автомобиля.
- Ручные ТПО/утиль привязаны к ID автомобиля, в том числе при позднем получении ID. Устаревшие настройки восстанавливают значения по умолчанию.
- Электромобилям необходим подтверждённый ручной утильсбор: прежняя безусловная сумма удалена.
- Сбой курсов не подменяет их образцами и не обновляет дату. Используются номиналы и дата источника. USDT/RUB вводится пользователем.
- Таблица CSV поддерживает кавычки и десятичную запятую. Другой год и тестовые строки не подставляются при отсутствии совпадения.
- Скидка и поправка внутреннего курса видны и редактируются. Неполный внутренний расчёт не показывает итог и маржу.
- Страховые данные не интерпретируются как подтверждение отсутствия ДТП.
- Фото берутся из реально загруженных изображений текущего объявления; несуществующие адреса больше не генерируются. Поддержан ID в пути URL.
- Нулевые расходы сохраняются и в печатной форме. Печатная форма помечена как предварительная; чужие реквизиты по умолчанию удалены. Ранее сохранённые реквизиты пользователя сохранены.

## Проверка и установка предварительной версии

Требуется Node.js с поддержкой node:test:

```
node --test tests/regression.test.cjs
node scripts/build.cjs
```

Открыть созданный `dist/vector-encar.user.js` в Tampermonkey. Отключить прежние отдельные модули, чтобы не было дублирования. Сборка фиксирует порядок загрузки модулей. Файл сборки не хранится в репозитории.

## Что пока требует проверки

- Новая таблица ТПО от владельца ожидается. Старая таблица и формула 48% сохранены только для предварительной оценки. Тарифы утильсбора не подтверждены; возраст и условия ввоза требуют отдельной актуальной модели.
- Автоматические проверки покрывают расчёт и обработку ошибок, а не живую вёрстку Encar. Работа на реальных объявлениях, печать, фотографии и переустановка Tampermonkey требуют проверки в браузере пользователя.
- Фотографии, ещё не загруженные страницей, могут отсутствовать. Не обходятся ограничения Encar.
- Новая вкладка и приём расчётов в CRM ещё не реализованы. Данные автомобилей CRM не меняются.

## Схема будущей интеграции без копирования ссылок

Вкладка «Расчёт Encar» открывает настоящий Encar. Пользователь просматривает объявления с панелью Tampermonkey и кнопкой «Сохранить расчёт в VECTOR». Скрипт передаёт разрешённый набор характеристик и исходных сумм в авторизованный приёмник CRM. Привязка по Encar ID и VIN; повторная отправка обновляет черновик расчёта, а не создаёт дубль автомобиля. Расчёт отделён от фактической себестоимости, перенос сумм выполняется явным действием с проверкой версии карточки. Доставка до Бишкека не учитывается дважды.

Токены сотрудников не размещаются в публичном скрипте: подключение конкретного устройства, ограниченное разрешение на импорт и возможность отзыва. API-ключи AI остаются на сервере. Обычный iframe не даёт CRM читать DOM Encar из-за same-origin policy; возможность встраивания зависит от заголовков самого сайта.
