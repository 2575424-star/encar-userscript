# VECTOR · Encar — калькулятор для Tampermonkey

Отдельное окно расчёта стоимости автомобиля **Корея → Бишкек → Воронеж** прямо на открытой странице Encar. Вход в VECTOR CRM не нужен.

## Установка

1. Установите расширение [Tampermonkey](https://www.tampermonkey.net/) в браузере, если его ещё нет.
2. **Отключите прежние модули Encar** и прежний скрипт «VECTOR Encar → CRM» в панели Tampermonkey, чтобы на странице не было двух калькуляторов. Их файлы в `libs/` сохранены для истории; отдельно устанавливать их не нужно.
3. [Установить калькулятор v2.0](https://raw.githubusercontent.com/2575424-star/encar-userscript/main/encar-calculator.user.js) → нажмите «Установить» в Tampermonkey.
4. Откройте или перезагрузите [объявление Encar](https://fem.encar.com/cars/detail/42752324). Окно появится автоматически; закрытое окно открывается кнопкой **«Рассчитать стоимость · VECTOR»** справа внизу или из меню расширения.

Если окно не появилось, проверьте, что новый скрипт включён и расширению разрешён доступ к Encar. Для Chromium настройка допуска пользовательских скриптов описана в [официальной справке Tampermonkey](https://www.tampermonkey.net/faq.php#Q209). После изменения настройки обновите страницу.

## Что делает

- Читает марку, модель, модификацию, год, пробег, объём, цену и доступный VIN из данных открытого объявления. Мощность заполняется только при наличии однозначных единиц PS/кВт; иначе вводится вручную.
- Преобразует цену Encar из «10 000 вон» в воны. Реальный объём сохраняется; только для подбора ТПО округляется вверх до ближайших 100 см³.
- Содержит таблицу из CRM: 690 строк за 2024–2026 годы. Выбирает только точное однозначное совпадение марки, модели, года и объёма. Можно найти строку вручную или указать стоимость в евро / готовую сумму ТПО.
- Загружает справочные курсы ЦБ через cbr-xml-daily.ru, показывает источник и дату. Курсы покупки и расходы редактируются.
- Показывает расшифровку и итог в рублях и долларах. Автоматический утильсбор применяется после подтверждения; смена параметров отменяет подтверждение. Ручная сумма, в том числе ноль, поддерживается.
- Сохраняет черновик отдельно для каждого объявления в хранилище Tampermonkey. Кнопка «Сохранить настройки» сохраняет общие расходы и курсы для новых машин. Цена, характеристики, ТПО и утильсбор между машинами не переносятся.
- Копирует полный расчёт в буфер обмена. При переходе на другой автомобиль внутри Encar переключает черновик.

## Формула из CRM

Все параметры редактируются. Начальные расходы:

| Параметр | Значение |
|---|---:|
| Скидка / возврат | 4% |
| Расходы до Бишкека | 6 000 000 ₩ |
| Брокер | 1 000 $ |
| Доставка Бишкек → Воронеж | 1 200 $ |
| Надбавка при переводе в рубли | 2% |
| Документы | 85 000 ₽ |

```text
Цена до Бишкека, $ = (цена ₩ × (1 − скидка/100) + расходы ₩) / курс ₩/$
ТПО, $ = стоимость по таблице € × 48% × курс $/€
Валютная часть, $ = цена до Бишкека + ТПО + брокер + доставка
Итого, ₽ = валютная часть × курс ₽/$ × (1 + надбавка/100) + документы + утильсбор
```

Автоматические ставки утильсбора перенесены из модуля CRM за 2026 год. Для автоматического предложения нужны фактический объём, мощность, тип ДВС, возраст на дату уплаты и стандартный режим ввоза. Для гибридов, электромобилей, другого года уплаты и особых условий используется ручная подтверждённая сумма. Год модели / регистрации не используется как доказательство точного возраста.

### Пример №42752324

При проверке 22.09.2026 страница содержала Mercedes-Benz GLE450d 4MATIC Coupe: 2023 год, 54 574 км, 2 989 см³, 81 900 000 ₩. Мощность с единицами в доступных данных отсутствовала. Таблица CRM не содержит 2023 года: нужно ввести стоимость в евро или сумму ТПО вручную, а также проверить мощность и возраст для утильсбора. Скрипт не подставляет тариф 2024 года вместо 2023 и не выдаёт неполный итог за окончательный.

## Данные и обновления

Скрипт не обращается к CRM и не отправляет расчёты на сервер. Характеристики читаются из JSON открытой страницы; API Encar используется как резерв. Для загрузки курсов выполняется запрос к cbr-xml-daily.ru. Для обновлений Tampermonkey использует этот GitHub-репозиторий. В скрипте нет ключей API, данных клиентов или удалённо исполняемых библиотек. Курсы и таблица не означают гарантированную итоговую стоимость сделки.

Старая папка `libs/` относится к предыдущей модульной версии; новая версия работает через один файл `encar-calculator.user.js`.

## Разработка и проверка

Нужен Node.js 20+; сторонние зависимости для сборки и модульных тестов не требуются.

```sh
npm test
npm run build
node --check encar-calculator.user.js
```

`src/encar.js`, `src/encar-util.js`, `src/encar-import.js` и таблица перенесены из расчётного раздела VECTOR CRM. В автономной версии добавлены обязательное подтверждение автоматического утильсбора и проверка типа двигателя: неизвестный тип, гибрид и электромобиль не считаются ДВС автоматически. `src/app.js` — окно, хранилище и интеграция Tampermonkey. `scripts/build.mjs` собирает один устанавливаемый файл без внешних runtime-зависимостей. Тестовый пример содержит только характеристики автомобиля без контактов продавца.
