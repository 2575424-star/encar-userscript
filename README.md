# VECTOR · Encar — калькулятор для Tampermonkey

Отдельное окно расчёта стоимости автомобиля **Корея → Бишкек → Воронеж** прямо на открытой странице Encar. Вход в VECTOR CRM не нужен.

## Установка

1. Установите расширение [Tampermonkey](https://www.tampermonkey.net/) в браузере, если его ещё нет.
2. **Отключите прежние модули Encar** и прежний скрипт «VECTOR Encar → CRM» в панели Tampermonkey, чтобы на странице не было двух калькуляторов. Их файлы в `libs/` сохранены для истории; отдельно устанавливать их не нужно.
3. [Установить / обновить калькулятор v2.1.0](https://raw.githubusercontent.com/2575424-star/encar-userscript/main/encar-calculator.user.js) → нажмите «Установить» или «Обновить» в Tampermonkey.
4. Откройте или перезагрузите [объявление Encar](https://fem.encar.com/cars/detail/42752324). Окно появится автоматически; закрытое окно открывается кнопкой **«Рассчитать стоимость · VECTOR»** справа внизу или из меню расширения.

Если окно не появилось, проверьте, что новый скрипт включён и расширению разрешён доступ к Encar. Для Chromium настройка допуска пользовательских скриптов описана в [официальной справке Tampermonkey](https://www.tampermonkey.net/faq.php#Q209). После изменения настройки обновите страницу.

## Что делает

- Читает марку, модель, модификацию, год, пробег, объём, цену и доступный VIN из данных открытого объявления. Мощность читается из Encar при наличии однозначных единиц PS/кВт; если её нет — предлагается из корейского справочника с источником и подтверждением.
- Преобразует цену Encar из «10 000 вон» в воны. Реальный объём сохраняется; только для подбора ТПО округляется вверх до ближайших 100 см³.
- Содержит таблицу из CRM: 690 строк за 2024–2026 годы. Учитывает разные написания марки, семейства и модификации. Однозначные нормализованные совпадения выбирает автоматически; близкие строки предлагает подтвердить. Можно найти строку вручную или указать стоимость в евро / готовую сумму ТПО.
- Загружает справочные курсы ЦБ через cbr-xml-daily.ru, показывает источник и дату. Курсы покупки и расходы редактируются.
- Показывает расшифровку и итог в рублях и долларах. Автоматический утильсбор применяется после подтверждения; смена параметров отменяет подтверждение. Ручная сумма, в том числе ноль, поддерживается.
- Сохраняет черновик отдельно для каждого объявления в хранилище Tampermonkey. Кнопка «Сохранить настройки» сохраняет общие расходы и курсы для новых машин. Цена и утильсбор между машинами не переносятся. Подтверждённые связи с ТПО и справочные мощности запоминаются отдельно для одинаковой модификации, года, рынка и фактического объёма.
- Копирует полный расчёт в буфер обмена. При переходе на другой автомобиль внутри Encar переключает черновик.

### Подбор ТПО и мощности v2.1.0

Для объявления №42403782 (`Mercedes-Benz`, `GLE-Class`, `GLE450d 4MATIC Coupe`, 2024, 2989 см³) предлагается строка **GLE 450 / 2024 / 3000 см³ / 31 000 €**. В ней нет суффикса `d`, поэтому она применяется только после нажатия «Подтвердить». Подтверждённая связь сохраняется в Tampermonkey и используется для такой же модификации. Изменение года, фактического объёма или стоимости строки не позволяет повторно применить старую связь.

Нормализация учитывает пробелы, дефисы, диакритику, `Class`, названия марки (`Benz`, `Mercedes-Benz`, `벤츠`), оборудование и обозначение двигателя в модификации. Числа и суффиксы силовой установки не исправляются по приблизительному сходству: `400d`, `450d`, `450e` и `53` не превращаются друг в друга. Год и округлённый объём ТПО должны совпадать. Если кандидатов несколько, скрипт показывает выбор. Ручной выбор строки также запоминается, если марка, год и объём совпадают. Изменение идентичности автомобиля сбрасывает старый ТПО и подтверждение утильсбора.

**Начальный справочник мощности ограничен одной модификацией:** GLE 450 d 4MATIC Coupé, корейский рынок, 2025 модельный год, 2989 см³, 367 л.с. Источник — [каталог Hansung Motor](https://mb.hansung.co.kr/Benz/suv_offroader/The%20new%20GLE%20Coup%C3%A9), поле `최고출력 (hp/rpm)` для `(25년식)`. Это запись каталога, а не расшифровка мощности конкретного VIN. Для автомобиля 2024 года она предлагается с явным предупреждением о соседнем годе. Встроенной записи за 2024 год пока нет.

Предложенная мощность подсвечивается. Сначала подтвердите её для данного автомобиля, затем утильсбор. Пока мощность из справочника не подтверждена, автоматический итог не выдаётся. При нескольких записях появляется выбор источника. Подтверждение запоминается как подсказка для той же модификации, но в новом объявлении мощность снова нужно подтвердить. Ручная правка мощности имеет приоритет.

Базу можно расширять без изменения скрипта: раздел **«Справочник мощности» → «Загрузить справочник JSON»**. Формат показан в [src/power-catalog.json](src/power-catalog.json). Загрузка заменяет предыдущую пользовательскую базу; встроенные записи и локальные подтверждения сохраняются. Поля `brand`, `model`, `trim`, `year`, `engine`, `market`, `powerHp`, `powerKind`, `source`, `sourceUrl` обязательны. `powerHp` задаётся в метрических л.с.; `engine` — фактические см³; `market` — `Корея`; `powerKind` — `engine` (двигатель) или `system` (система). Суммарная мощность гибридной системы не подставляется в поле мощности ДВС. Источник — HTTPS-ссылка. Кнопка «Забыть сохранённые соответствия» очищает локальные связи и загруженную базу, сохраняя текущий расчёт.

Для подбора мощности нужны модификация, кузов, фактический объём, год и рынок. Один объём, например «3.0», не определяет мощность. Поиск допускает соседний модельный год только как предложение с предупреждением. Полная база всех автомобилей корейского рынка и внешнее API в этой версии не подключены. Базу следует пополнять проверенными корейскими каталогами производителей и дилеров.

### Исправление v2.0.1

Исправлена загрузка повторно размещённых объявлений: Encar может использовать разные номера для объявления и внутренней карточки машины. Например, ссылка №42403782 соответствует `queryCarId` / `manage.dummyVehicleId`, а внутренний `vehicleId` равен 42393681. Теперь оба способа чтения (страница и резервный API) принимают явно указанную Encar связь, при этом данные постороннего автомобиля по-прежнему отклоняются. После обновления пустые черновики, сохранённые при неудачной загрузке, заполняются автоматически. Установите обновление по ссылке выше и перезагрузите вкладку Encar.

## Формула из CRM

Все параметры редактируются. Начальные расходы:

| Параметр | Значение |
|---|---:|
| Скидка / возврат | 4% |
| Расходы до Бишкека | 6 000 000 ₩ |
| Брокер | 1 000 $ |
| Доставка Бишкек → Воронеж | 1 200 $ |
| Надбавка при переводе в рубли | 2% |
| Документы | 85 000 ₽ |

```text
Цена до Бишкека, $ = (цена ₩ × (1 − скидка/100) + расходы ₩) / курс ₩/$
ТПО, $ = стоимость по таблице € × 48% × курс $/€
Валютная часть, $ = цена до Бишкека + ТПО + брокер + доставка
Итого, ₽ = валютная часть × курс ₽/$ × (1 + надбавка/100) + документы + утильсбор
```

Автоматические ставки утильсбора перенесены из модуля CRM за 2026 год. Для автоматического предложения нужны фактический объём, мощность, тип ДВС, возраст на дату уплаты и стандартный режим ввоза. Для гибридов, электромобилей, другого года уплаты и особых условий используется ручная подтверждённая сумма. Год модели / регистрации не используется как доказательство точного возраста.

### Пример №42752324

При проверке 22.09.2026 страница содержала Mercedes-Benz GLE450d 4MATIC Coupe: 2023 год, 54 574 км, 2 989 см³, 81 900 000 ₩. Мощность с единицами в доступных данных отсутствовала. Таблица CRM не содержит 2023 года: нужно ввести стоимость в евро или сумму ТПО вручную, а также проверить мощность и возраст для утильсбора. Скрипт не подставляет тариф 2024 года вместо 2023 и не выдаёт неполный итог за окончательный.

## Данные и обновления

Скрипт не обращается к CRM и не отправляет расчёты на сервер. Характеристики читаются из JSON открытой страницы; API Encar используется как резерв. Для загрузки курсов выполняется запрос к cbr-xml-daily.ru. Для обновлений Tampermonkey использует этот GitHub-репозиторий. В скрипте нет ключей API, данных клиентов или удалённо исполняемых библиотек. Курсы и таблица не означают гарантированную итоговую стоимость сделки.

Старая папка `libs/` относится к предыдущей модульной версии; новая версия работает через один файл `encar-calculator.user.js`.

## Разработка и проверка

Нужен Node.js 20+; сторонние зависимости для сборки и модульных тестов не требуются.

```sh
npm test
npm run build
node --check encar-calculator.user.js
```

`src/encar.js`, `src/encar-util.js`, `src/encar-import.js` и таблица перенесены из расчётного раздела VECTOR CRM. В автономной версии добавлены обязательное подтверждение автоматического утильсбора и проверка типа двигателя: неизвестный тип, гибрид и электромобиль не считаются ДВС автоматически. `src/app.js` — окно, хранилище и интеграция Tampermonkey. `scripts/build.mjs` собирает один устанавливаемый файл без внешних runtime-зависимостей. Тестовый пример содержит только характеристики автомобиля без контактов продавца.
